# Carlsberg Websites: 2026 Year in Review

A cinema-themed yearly review for the Digital Marketing IIT web team.

## Web presentation

Open `index.html` in a browser. Each scroll gesture moves one slide down or up.

| Action | Keys |
| --- | --- |
| Next slide | Click, scroll down, ↓, →, Space, Page Down, swipe up |
| Previous slide | Shift + click, scroll up, ↑, ←, Page Up, swipe down |
| First / last slide | Home / End |
| Fullscreen | F |
| Mute / unmute music | M, or the speaker button (top right) |

The dots on the right jump to any slide, and `index.html#12` opens slide 12 directly.

### Intro music

The first slide plays `assets/intro.mp3`. Browsers only allow sound after a click or key press, so on the first slide the first click (or Enter / Space) starts the music instead of moving on. The music fades out when you leave the slide and back in if you return. If you scroll first, the slide changes and no music plays.

The current file is an original placeholder (a synthesised string swell with timpani). To use another track, replace `assets/intro.mp3` with your own file under the same name. It loops, so a track that loops cleanly works best.

- `index.html`: slide content
- `style.css`: layout, colours and animations
- `script.js`: scroll, keyboard, touch and dot navigation
- `assets/`: posters, headshots, logos and background
